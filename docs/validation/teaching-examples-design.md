# 演示案例实现与验证记录

> 日期：2026-09-20
>
> 范围：合成案例加载、正常产品计算、独立结果核验、可选短说明页

## 已实现

- 输入工作区提供一个“试用示例”入口，支持“基础计算”和“多燃料比较”。
- 两个示例请求分别精确对应独立冻结案例 `A-2025` 与 `B-default`。
- 示例资源只包含合成元数据和产品请求，不包含 `expected.json`、产品结果或标准答案。
- 资源通过版本、请求结构、十进制字符串、燃料路径、候选 ID、资格字段和 RFNBO `E + eu` 校验后，才替换当前表单。
- 加载后沿用现有 `/api/calculate`、结果展示和 CSV/PDF 导出链路。
- 用户修改输入后，旧结果和导出立即失效，并显示“合成示例 · 已修改”。
- 修改后的示例再次加载需要确认；取消时保留当前输入和状态。
- 目录燃料与高级自定义分别保存前端草稿；草稿字段不进入 API 请求。
- 目录路径变化会清除旧路径的资格、`E`、`eu` 和生物质分数。
- `/examples/guide` 提供两个案例的短说明和合成数据边界。
