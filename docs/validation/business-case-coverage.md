# 合成业务案例覆盖矩阵

本文件记录 2026-09-18 冻结的合成业务案例覆盖。它服务于系统独立核验，以及未来制作教程和演示时选择案例，不包含教程正文、演示脚本或真实业务验收结论。

## 1. 集合边界

| 指标 | 当前值 | 说明 |
| --- | ---: | --- |
| 完整自动集 | 61 个请求 | A=7、B=18、C=8、D=28 |
| 精简案例集 | 8 个请求 | A=2、B=2、C=2、D=2，是完整集的子集 |
| 完整集独有变体 | 53 个请求 | 边界、异常、资格、设备、目录和组合条件 |
| 候选输入 | 231 个 | 其中 221 个有独立冻结的可解析因子快照 |
| compact 浏览器代表 | 8 个 | 桌面和移动视口使用 DOM/API 内容断言，不保存截图 |
| 独立参考实现 | 1 套 | Python 标准库精确有理数计算，不导入生产计算模块 |
| 内置请求路径冒烟覆盖 | 36 个 | 合并为 6 个 smoke 请求；不包含 OPS |

“案例族数量”不能替代请求数量。上表把案例族、完整请求、精简请求和变体分别计数。

## 2. 功能覆盖

| 功能点 | 独立参考内容 | 主要见证 |
| --- | --- | --- |

| 2024 FuelEU 不适用 | `null`、原因码、清缴率 0.4、EU ETS 仅 CO2 | `A-2024` |

## 3. 精简集选择

| 案例 | 保留原因 |
| --- | --- |
| `A-2024` | 年度、半范围、FuelEU 不适用和 B0 最小值 |
| `A-manual-zero` | 不依赖复杂因子的手算能源与零值锚点 |
| `B-default` | 六报价、供应约束、目标、最大改善、排序和切换 |
| `B-combined-constraints` | 同一候选同时受预算、供应和上限约束 |
| `C-OTTO_MS-2025` | 四种甲烷滑移设备中滑移最大的 2025 年代表 |
| `C-OTTO_MS-2026` | 与 2025 组成三气体清缴控制对 |
| `D-custom-rfnbo_e` | 自定义公式、证据、RWD 和资格代表 |
| `D-missing-evidence` | 候选局部阻断而 B0/对照保留 |

精简集没有覆盖零范围、HTTP 422、输入反序、并列、全部资格和设备组合，也不能独自证明完整自动集通过。

## 4. 尚未覆盖或只部分覆盖

1. 没有 2027–2029 年案例，也没有无效年份、无效港口、未知港口或反向港口对。
2. 半范围只有 B0；没有同一混兑方案的 0.5/1 成对对照，零范围没有候选方案。
3. 36 路径 smoke 只验证默认解析和主要回退，不逐一生成每个路径的真实混兑决策。
4. 没有真实 RED/FuelEU 认证文件、认证批次或供应合同；`VERIFIED` 只验证接口状态和合成证据。
5. 没有自定义全字段真实单位换算、部分证据混合状态、负 Cslip、超过 100% 滑移、缺甲烷 Cslip 等扩展负例。
6. 没有负/零 LCV、无效 RWD、非有限数、负价格/预算/供应、重复候选 ID、全部候选阻断等一般解析边界。
7. 未验证 OPS、岸电、多设备质量分配、年度池化/借用/结转、正式年度罚款、汇率或物理生命周期 WtW。
8. 浏览器覆盖的是 compact 渲染与三个实际表单流程，不代替所有 61 个请求的 UI 输入验证。

## 5. 可复用范围

这些案例可以作为未来教程和演示的数据来源，但当前阶段没有制作教程正文、演示脚本、截图或一键加载功能。使用案例时必须保留 `synthetic=true`、合成数据声明、资格假设和“执行条件待确认”边界。
