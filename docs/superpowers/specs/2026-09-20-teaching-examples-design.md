# 系统演示案例设计

> 日期：2026-09-20
>
> 状态：已实施并完成自动验证
>
> 后续教程设计见 [示例就地教程设计规格](2026-09-20-contextual-example-tutorial-design.md)（已实施；自动与内部验证完成，真人新手验收待执行）。本文件的“已实施”仅指原示例加载功能；下文引导修改HVO供应量的教学要求已由后续设计取消，正常编辑功能和相关核验案例仍保留。
>
> 目的：让第一次使用系统的人能用极少操作完成“加载示例、看结果、改一个条件、重新计算”，同时保证示例输入可以由现有独立参考核验资产追溯。

## 1. 问题定义

当前系统已经有完整的手动输入、决策工作台、CSV/PDF 导出和独立业务案例核验资产，但新用户需要自行填写较多港口、燃料、报价、资格和约束字段，无法快速建立对产品的正确理解。

演示模式的本质是降低第一次输入成本，不增加一套平行计算系统。因此示例加载后必须填入现有表单，并调用现有 `/api/calculate`；结果、推荐、导出和错误处理继续使用产品当前链路。

本功能服务于两种场景：

- 新手：通过两个短案例理解 B0、方案比较和约束变化；
- 演示者：快速展示完整结果和一次条件变化。

## 2. 范围与非目标

### 2.1 本期范围

- 在现有输入工作区提供一个“试用示例”入口；
- 提供两个示例：基础计算、多燃料比较；
- 示例使用真实产品请求结构，加载后自动计算；
- 多候选案例保留完整候选，但教程只聚焦 B0、HVO 和 UCO；
- 允许用户修改任意输入，再使用原有计算按钮重新计算；
- 目录燃料的资格、批次 E、eu 和合格生物质分数可查看；
- 输入模式切换时分别保留目录模式草稿和自定义模式草稿；
- 手动修改后再次加载示例需要确认，取消确认必须保留输入和当前结果；
- 示例资源损坏、请求失败或版本不支持时，在替换输入前失败，保留当前页面状态；
- 增加一页可选的极简案例说明，不做强制向导；
- 通过浏览器测试实际表单提交，并与独立参考结果逐项核对；
- 示例资源随 Python wheel 一起发布。

### 2.2 本期不做

- 案例管理后台、用户自定义示例保存、学习进度、测验和视频；
- 一键加载全部 61 个核验案例；
- 把 `expected.json`、标准答案或产品内部结果发送到浏览器；
- 为示例新增计算接口、推荐算法或公式；
- 自动把用户自由修改的结果标记为“已独立核验”；
- 气体滑移、自定义证据和认证案例的教程正文；
- 真实业务数据、真实报价、真实认证或采购建议。

## 3. 用户体验设计

### 3.1 入口

输入区标题旁放置一个“试用示例”按钮。点击按钮展开两个选项：

1. `基础计算`：2025 年 CNSHG → NLRTM，1000 吨 MDO，只有 B0；
2. `多燃料比较`：2030 年 NLRTM → DEHAM，1000 吨 MDO，六个独立候选。

菜单必须支持鼠标和键盘：按钮拥有 `aria-expanded`，选项可聚焦，按 Escape 关闭并将焦点还给入口按钮。移动端不产生横向溢出。

### 3.2 加载流程

1. 页面初始化完成且燃料目录可用后，启用入口按钮；
2. 用户选择示例；
3. 浏览器获取静态示例资源；
4. 在内存中完成版本、元数据、请求结构、港口格式、燃料路径、数值范围和候选 ID 校验；
5. 校验成功后一次性替换表单输入；
6. 调用现有计算流程；
7. 保留结果工作区的原有展示、导出和选择交互，并在输入区和结果区显示“合成示例”状态。

资源获取或校验失败时，不能先清空或部分替换输入。错误显示在示例入口附近，当前输入、当前结果和导出状态保持不变。

### 3.3 修改与重新计算

加载示例后，任何用户输入修改都显示“已修改”，并使当前结果和导出按钮失效，防止导出旧结果。用户点击原有计算按钮后，结果通过正常 API 生成。

示例说明引导用户只修改一个条件：把 HVO 的供应量改为 `0`。该操作对应独立案例 `B-hvo-supply0`，用于验证“达到 GHGI 参考线的最低成本”从 HVO 转为 UCO bulk。

重新加载示例时：

- 未发生手动修改：直接替换；
- 已发生手动修改：弹出一次确认；取消则保留输入和结果，确认才替换并计算。

### 3.4 输入模式草稿

每个候选同时维护两份前端草稿：

- `builtinDraft`：路径、资格状态、E、eu、合格生物质分数；
- `customDraft`：自定义名称、燃料类型、WtT 模式、LCV、WtT/E/eu、燃烧因子、滑移、资格、来源证据等。

草稿只用于表单重绘，不发送无关字段到 API。切换路径时清除该路径的目录资格草稿，避免把旧燃料资格带到新路径；新增或删除其他候选不得改变剩余候选草稿。

目录燃料的高级区域默认折叠，摘要显示当前已设置的资格和批次值。选择 `VERIFIED_ELIGIBLE` 的 RFNBO 必须显示并提交 `eu`，否则前端校验应阻止提交并说明缺少使用阶段排放因子。

## 4. 示例数据契约

资源路径：`src/voyage_fuel/static/teaching-examples.json`。

```json
{
  "version": 1,
  "examples": {
    "basic": {
      "name": "基础计算",
      "caseId": "A-2025",
      "synthetic": true,
      "request": {}
    },
    "comparison": {
      "name": "多燃料比较",
      "caseId": "B-default",
      "synthetic": true,
      "request": {}
    }
  }
}
```

实际 `request` 必须与 `tests/fixtures/business-cases/<caseId>/request.json` 完全一致。资源只保存请求，不保存 `expected.json`、产品结果、快照 ID 或标准答案。`caseId` 用于测试关联和文档追溯，不作为运行时计算输入。

资源校验至少检查：

- 顶层 `version == 1`；
- 示例有非空名称、稳定 caseId、`synthetic == true`；
- 请求拥有年份、港口、确认标记、币种、基准燃料、基准质量、基准价格、EUA 价格和候选数组；
- 数字字段使用十进制字符串，质量、价格、比例和分数在允许范围内；
- 燃料路径来自 `/api/fuels`；
- 候选 ID 非空且不重复；
- 示例只允许现有产品请求支持的内置路径，不能隐藏自定义因子；
- 每个 RFNBO 已核验候选同时有 E 和 eu；
- 请求验证结束后才能更新 DOM。

## 5. 教学说明边界

说明页路径为 `/examples/guide`，可从输入区链接打开，不覆盖当前工作状态。正文只包含两部分：

- 基础计算：说明 B0、燃料成本、EUA 成本、模型成本和 FuelEU 指示性金额的区别；
- 多燃料比较：说明六个候选分别与同一 B0 比较，并把 HVO 供应量改为 0，观察推荐变化。

说明页必须保留以下边界：

- 全部价格、用量、供应和资格均为合成输入；
- 1000 吨是测试能源设定，不是航线典型油耗；
- “假设合格”和“已核验合格”不代表真实认证；
- 结果是航次级 FuelEU/EU ETS 估算，不是正式年度罚款或采购建议；
- 用户自由修改不自动获得独立核验结论。

## 6. 技术边界

### 6.1 前端

修改 `src/voyage_fuel/static/app.js`，但不在浏览器重新计算任何成本、比例、排序或切换点。前端只负责资源校验、表单投影、状态失效和现有 API 调用。

### 6.2 后端

不增加示例专用 API。静态资源由现有 `StaticFiles` 提供；新增说明页只增加一个模板路由。现有 `/api/calculate`、`/api/export/csv`、`/api/export/pdf` 合同保持不变。

### 6.3 独立核验

新增浏览器测试在调用产品前运行 `business_case_worker.py`，确认冻结参考指纹和 `production_modules_loaded == []`。测试至少核对：

- 基础示例两个视图的实际提交和 API 结果；
- 多燃料六个候选、完整结果、导出；
- HVO 供应量为 0 的实际提交和推荐变化；
- RFNBO 未证明回退和已核验 E/eu 分支；
- 输入模式草稿、损坏资源、失败加载、覆盖确认、移动端布局。

## 7. 验收标准

### 用户操作

1. 新用户无需手填即可从入口加载两个示例并看到结果；
2. 修改一个供应条件后，旧结果不能继续导出，重新计算后推荐随条件变化；
3. 加载失败或取消覆盖不会破坏当前输入和结果；
4. RFNBO 已核验分支不会因缺少 eu 隐式阻断；
5. 390px 移动端入口、菜单、输入和结果无页面横向溢出。

### 工程质量

1. 示例输入与独立核验 fixture 一致，浏览器不接收标准答案；
2. 现有 API、导出和计算逻辑没有新增分支；
3. 示例资源能进入 wheel，安装后静态资源和说明页可访问；
4. 新增测试覆盖正常、失败、边界和状态保留；
5. 全量 Python、Node、独立业务案例核验和浏览器回归通过。

## 8. 验收边界

本功能完成只代表演示入口和案例说明可用，不代表真实业务验收。真实港口事实、燃料来源、认证、设备兼容、报价和年度 FuelEU 结算仍在范围外。
